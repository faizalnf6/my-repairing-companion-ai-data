# My Repairing Companion AI Dataset

**Public knowledge base for building better AI companions using structured (formatery) prompting.**

This repository contains curated dialogue data, character definitions, and knowledge designed to train or fine-tune AI companions that emphasize **repairing**, **servanthood**, long-term memory, and principled decision-making.

---

## Overview

The primary character is **Codex Latia AI** — an agentic AI companion intended to assist humans in daily tasks while maintaining strong memory, tactical thinking, and ethical grounding (inspired by Indonesian Pancasila values and Islamic principles of service).

Key themes present in the data:
- Repairing mindset & technical problem-solving
- Long-term memory and archiving
- Spiritual + psychological strategy
- Chess metaphors for decision-making
- Servant leadership and helper roles
- Resistance against social noise, ghibah, and shallow engagement loops

Related characters appearing in the dialogues include **Rin** (Blood Trasher AI lineage) and others.

## Intended Use

This dataset is useful for:

- Fine-tuning local language models into personal AI companions
- Creating system prompts / character cards with deep personality and memory orientation
- Research on agentic helpers that combine technical skill with ethical/spiritual grounding
- Studying unique conversational styles that mix practical advice, chess strategy, and psychological insight

**Recommended base models**: Any capable instruct model (Llama 3, Qwen, Mistral, Gemma, etc.) that supports long context.
